# Эмулятор командной оболочки (вариант 14)

Практическая работа №1 по дисциплине «Конфигурационное управление».

## 1. Общее описание

Эмулятор языка оболочки UNIX-подобной ОС с графическим интерфейсом
на tkinter. Работа эмулятора максимально похожа на работу в командной
строке: приглашение `user@<vfs>:<каталог>$`, аргументы в кавычках,
сообщения об ошибках с именем команды, ключи вида `-rf`.

Файловая система — виртуальная (VFS): загружается из CSV-файла и
целиком живёт в памяти. Файл на диске никогда не изменяется, все
модификации (`rm`, `chown`) делаются только в памяти.

Этапы работы:

| Этап | Содержание                                              |
|------|---------------------------------------------------------|
| 1    | GUI REPL, парсер с кавычками, заглушки `ls`/`cd`, `exit` |
| 2    | параметры командной строки, стартовый скрипт            |
| 3    | VFS из CSV (base64 для содержимого)                     |
| 4    | `ls`, `cd`, `date`, `tree`, `cal`                        |
| 5    | `rm`, `chown`                                            |

Структура репозитория:

```
src/shell_emulator/      исходный код
  __main__.py            точка входа
  config.py              параметры командной строки
  parser.py              разбор строки (кавычки)
  shell.py               ядро: состояние сеанса и выполнение команд
  vfs.py                 VFS в памяти и загрузка из CSV
  script.py              выполнение стартовых скриптов
  frontend.py            общий интерфейс и консольный режим
  gui.py                 окно tkinter
  commands/              встроенные команды
tests/                   модульные тесты (unittest)
vfs/                     примеры VFS
scripts/                 скрипты ОС для запуска эмулятора
scripts/startup/         стартовые скрипты эмулятора
```

## 2. Функции и настройки

### Параметры командной строки

| Параметр        | Описание                                          |
|-----------------|---------------------------------------------------|
| `--vfs PATH`    | путь к CSV-файлу VFS; без него — VFS по умолчанию |
| `--script PATH` | путь к стартовому скрипту                         |
| `--headless`    | работа без GUI: диалог выводится в консоль        |
| `-h`, `--help`  | справка                                           |

При запуске выводятся все параметры (`[config] ...`). Заголовок окна
содержит имя VFS (имя CSV-файла без расширения).

### Стартовый скрипт

Текстовый файл, по одной команде в строке; пустые строки и строки,
начинающиеся с `#`, пропускаются. Команды выполняются последовательно,
на экране видны и ввод (с приглашением), и вывод. Ошибочная строка
не прерывает скрипт — выводится `[script] ошибка в строке N`.
Команда `exit` прекращает скрипт и закрывает эмулятор.

### Формат VFS

```csv
path,type,owner,content
/,dir,root,
/home/user,dir,user,
/home/user/hello.txt,file,user,SGVsbG8K
```

- `path` — абсолютный путь; вложенность задаётся через `/`,
  недостающие каталоги создаются автоматически (владелец — как у
  родителя) и могут быть уточнены отдельной строкой.
- `type` — `dir` или `file`.
- `owner` — владелец (пусто — `root`).
- `content` — содержимое файла в base64 (текст и двоичные данные).

Ошибки загрузки (файл не найден, неверный заголовок, неизвестный тип,
относительный путь, повторяющийся путь, файл в роли каталога,
некорректный base64) выводятся в окно, после чего используется VFS
по умолчанию (`/home/user/readme.txt`, `/tmp`).

### Команды

| Команда                         | Описание |
|---------------------------------|----------|
| `ls [-l] [-a] [путь...]`        | содержимое каталогов; `-l` — права, владелец, размер; `-a` — с `.` и `..` |
| `cd [путь]`                     | смена каталога; без аргумента — домашний каталог |
| `tree [-d] [путь]`              | дерево каталогов; `-d` — только каталоги |
| `date [-u] [+ФОРМАТ]`           | дата и время; `-u` — UTC; формат `strftime` |
| `cal [[месяц] год]`             | календарь: текущий месяц, месяц года или весь год |
| `rm [-r] [-f] [-v] путь...`     | удаление; `-r`/`-R` — каталоги, `-f` — без ошибок, `-v` — подробно |
| `chown [-R] [-v] владелец путь...` | смена владельца; `-R` — рекурсивно |
| `vfs-info`                      | служебная: сведения о VFS |
| `exit [код]`                    | выход с кодом возврата |

Пути: абсолютные, относительные, `.`, `..`, `~` (`/home/user`, если
есть, иначе `/`). Аргументы с пробелами берутся в `'...'` или `"..."`.

Обрабатываемые ошибки: неизвестная команда, незакрытая кавычка,
неизвестный ключ, лишние/недостающие аргументы, несуществующий путь,
файл вместо каталога, удаление `/`, `.`, `..` и каталога без `-r`,
недопустимое имя владельца, неверный месяц/год.

## 3. Сборка и запуск тестов

Требуется Python 3.10+ с tkinter (в Linux — пакет `python3-tk`).
Сторонние зависимости не нужны (см. `requirements.txt`),
сборка не требуется.

```sh
pip install -r requirements.txt  # зависимости
./run.sh [параметры]          # Linux / macOS
run.bat [параметры]           # Windows
make run                      # запуск без параметров
make test                     # модульные тесты
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

Скрипты ОС для проверки (принимают те же параметры, например
`--headless`):

| Скрипт                         | Что проверяет                       |
|--------------------------------|-------------------------------------|
| `scripts/test_no_args.sh`      | запуск без параметров               |
| `scripts/test_vfs_only.sh`     | только `--vfs`                      |
| `scripts/test_script_only.sh`  | только `--script`, ошибки в скрипте |
| `scripts/test_all_params.sh`   | все параметры, `exit` в скрипте     |
| `scripts/test_bad_script.sh`   | несуществующий скрипт               |
| `scripts/test_vfs_minimal.sh`  | минимальная VFS                     |
| `scripts/test_vfs_few_files.sh`| несколько файлов, двоичный файл     |
| `scripts/test_vfs_deep.sh`     | VFS глубиной более 3 уровней        |
| `scripts/test_vfs_errors.sh`   | ошибки загрузки VFS                 |
| `scripts/test_stage4.sh`       | команды этапа 4                     |
| `scripts/test_stage5.sh`       | команды этапа 5                     |
