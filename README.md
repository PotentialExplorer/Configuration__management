# Эмулятор командной оболочки (вариант 14)

Практическая работа №1 по дисциплине «Конфигурационное управление».

Эмулятор языка оболочки UNIX-подобной ОС с графическим интерфейсом
(tkinter). Реализация на Python 3.

## Этап 1. REPL

- GUI-окно с областью вывода и строкой ввода.
- Заголовок окна содержит имя VFS.
- Парсер корректно обрабатывает аргументы в кавычках (`'...'`, `"..."`).
- Сообщения об ошибках: неизвестная команда, неверные аргументы,
  незакрытая кавычка.
- Команды-заглушки `ls`, `cd` выводят своё имя и аргументы.
- Команда `exit [код]` закрывает окно.

## Сборка и запуск

Требуется Python 3.10+ с модулем tkinter.

```sh
pip install -r requirements.txt
./run.sh          # Linux / macOS
run.bat           # Windows
make test         # тесты
```

## Пример

```
default:~$ ls -l "My Documents"
ls: args=['-l', 'My Documents']
default:~$ foo
foo: команда не найдена
default:~$ cd a b
cd: слишком много аргументов
default:~$ exit
```
