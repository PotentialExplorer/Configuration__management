# Эмулятор командной оболочки (вариант 14)

Практическая работа №1 по дисциплине «Конфигурационное управление».

Эмулятор языка оболочки UNIX-подобной ОС с графическим интерфейсом
(tkinter). Реализация на Python 3.

## Этап 1. REPL

- GUI-окно с областью вывода и строкой ввода.
- Заголовок окна содержит имя VFS.
- Парсер корректно обрабатывает аргументы в кавычках (`'...'`, `"..."`).
- Сообщения об ошибках: неизвестная команда, неверные аргументы,
  незакрытая кавычка.
- Команды-заглушки `ls`, `cd` выводят своё имя и аргументы.
- Команда `exit [код]` закрывает окно.

## Этап 2. Конфигурация

Параметры командной строки:

| Параметр          | Описание                                        |
|-------------------|-------------------------------------------------|
| `--vfs PATH`      | путь к физическому расположению VFS             |
| `--script PATH`   | путь к стартовому скрипту                       |
| `--headless`      | работа без GUI (диалог выводится в консоль)     |

При запуске выводятся все заданные параметры (`[config] ...`).
Стартовый скрипт выполняется построчно, ввод и вывод отображаются как
в диалоге; ошибочные строки пропускаются с сообщением
`[script] ошибка в строке N`. Скрипты ОС для проверки параметров
лежат в `scripts/test_*.sh`.

## Этап 3. VFS

Источник VFS — CSV-файл с заголовком `path,type,owner,content`:

```csv
path,type,owner,content
/,dir,root,
/home/user,dir,user,
/home/user/hello.txt,file,user,SGVsbG8K
```

- Вложенность задаётся абсолютным путём через `/`; недостающие
  промежуточные каталоги создаются автоматически.
- Содержимое файлов (текстовых и двоичных) хранится в base64.
- Файл на диске только читается, все операции идут в памяти.
- Ошибки загрузки (файл не найден, неверный заголовок, тип, base64,
  повторяющийся путь, файл в роли каталога) выводятся в окно,
  после чего используется VFS по умолчанию.
- Служебная команда `vfs-info` показывает сведения о VFS.

Примеры VFS лежат в `vfs/`: `minimal.csv`, `few_files.csv`, `deep.csv`
и испорченные `broken_*.csv`. Скрипты ОС: `scripts/test_vfs_*.sh`.

## Этап 4. Основные команды

| Команда                     | Описание                                     |
|-----------------------------|----------------------------------------------|
| `ls [-l] [-a] [путь...]`    | содержимое каталогов; `-l` подробно, `-a` с `.` и `..` |
| `cd [путь]`                 | смена каталога; без аргумента — `~`          |
| `tree [-d] [путь]`          | дерево каталогов; `-d` только каталоги       |
| `date [-u] [+ФОРМАТ]`       | дата и время; `-u` UTC; формат `strftime`    |
| `cal [[месяц] год]`         | календарь месяца или года                    |

Пути: абсолютные, относительные, `.`, `..`, `~` (`/home/user`).
Скрипт проверки: `scripts/test_stage4.sh`
(`scripts/startup/stage4.txt`).

## Сборка и запуск

Требуется Python 3.10+ с модулем tkinter.

```sh
pip install -r requirements.txt
./run.sh          # Linux / macOS
run.bat           # Windows
make test         # тесты
```

## Пример

```
default:~$ ls -l "My Documents"
ls: args=['-l', 'My Documents']
default:~$ foo
foo: команда не найдена
default:~$ cd a b
cd: слишком много аргументов
default:~$ exit
```
